# Подключение OpenAI к боту

## Что уже сделано в коде

- **Экономия токенов:** сначала срабатывают **скрипты** (`src/intentScripts.js`) — приветствия, «спасибо», отказ от off-topic, подсказки «запись/пробный/отмена/отзывы», совпадение с FAQ и короткие ответы по цене/расписанию/подходу **без вызова OpenAI**.
- Только если ответ не получен скриптами и задан `OPENAI_API_KEY`, вызывается API с **коротким** системным промптом (`TUTOR_SYSTEM_PROMPT_COMPACT`) и **урезанным блоком фактов** (лимиты длины в `buildFactsBlockCompact` в `src/aiAnswer.js`).
- Повтор той же формулировки берётся из **кэша в памяти** (до 150 записей) — повторный запрос к API не идёт.
- Индикатор **«печатает…»** показывается **только** перед реальным запросом к OpenAI, не перед ответом скриптом.
- Свободный текст в **главном меню**, **FAQ** и **отзывах**, режим **«Задать вопрос»** — общая логика выше.
- Параметры API по умолчанию: **gpt-4o-mini**, **temperature 0.3**, **max_tokens 280** (правится в `src/aiAnswer.js`).
- Если ключа нет или API недоступен, ответ строится **скриптами** и **fallback** по FAQ из базы.

## Что сделать вам

### 1. Получить API-ключ OpenAI

1. Зайдите на [platform.openai.com](https://platform.openai.com) и войдите в аккаунт (или зарегистрируйтесь).
2. Откройте раздел **API keys** и создайте новый ключ (**Create new secret key**).
3. Скопируйте ключ (начинается с `sk-...`). Храните его как пароль: не публикуйте в чатах и не коммитьте в git.

### 2. Прописать ключ в `.env`

В папке с ботом должен быть файл `.env` (его нет в репозитории — это нормально). Скопируйте из `.env.example` и добавьте:

```env
OPENAI_API_KEY=sk-ваш_ключ_сюда
```

Опционально:

```env
OPENAI_MODEL=gpt-4o-mini
```

### 3. Перезапустить бота

Остановите процесс (Ctrl+C) и снова запустите:

```bash
npm start
```

### 4. Проверить в Telegram

- Напишите боту **обычным текстом** из главного экрана (не нажимая кнопку), например: «хочу попробовать урок» или «сколько стоит» — должен прийти осмысленный ответ, иногда после короткой паузы с индикатором набора.
- Команды вида `/что-то`, которых нет у бота, обрабатываются отдельно (не как запрос к AI).

## Где менять поведение модели

| Что | Файл |
|-----|------|
| Системный промпт (правила ассистента) | `src/tutorSystemPrompt.js` |
| Модель, температура, max_tokens, сбор фактов из БД | `src/aiAnswer.js` |
| Когда вызывается AI (какие состояния чата) | `src/bot.js` (обработчик `text`) |
| Сами цены, FAQ, слоты в ответах | база SQLite + seed в `src/db.js` или правки в БД |

## Если что-то не работает

- **Нет ответа или ошибка в консоли** — проверьте баланс/лимиты на [platform.openai.com](https://platform.openai.com), верность ключа и интернет.
- **Ответы «как без нейросети»** — в `.env` пустой `OPENAI_API_KEY` или ключ не подхватился (перезапустите бота после правки `.env`).
- **Слишком длинные ответы** — уменьшите `MAX_TOKENS` в `src/aiAnswer.js`.

## Вопросы к заказчику (школе)

- Нужны ли другие запреты/формулировки в промпте — правьте `src/tutorSystemPrompt.js`.
- Нужно ли **не** слать в AI сообщения короче N букв — можно добавить условие в `bot.js`.

Если нужно, чтобы я поменял код под другие правила — включите режим Agent в Cursor и опишите задачу.
